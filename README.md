# 🏋️ GymMaster — Система управления расписанием тренировок

Приложение для организации расписания тренировочных групп в спортивном зале с поиском за O(1).

## О проекте

GymMaster — учебный Java-проект, моделирующий систему записи тренировок в спортзале. Позволяет составлять расписание занятий, назначать тренеров на группы и быстро находить нужные тренировки по дню и времени.

Проект написан в рамках курса **«Java-разработчик»** от Яндекс Практикума.

## Функциональность

- Добавление тренировочных сессий в расписание
- Поиск всех тренировок по дню недели — **O(1)**
- Поиск тренировок по дню недели и времени суток — **O(1)**
- Хранение информации о тренерах и группах

## Технологический стек

- **Java** — основной язык
- **HashMap** — вложенные структуры для O(1) поиска
- **ООП** — инкапсуляция, объектная модель предметной области
- **JUnit** — юнит-тестирование

```
test/ru/yandex/practicum/gym/
└── ...                   # Юнит-тесты (JUnit)
```

## Ключевые решения

### Хранилище с O(1) поиском

Расписание реализовано на вложенных `HashMap`:

```java
Map<DayOfWeek, Map<TimeOfDay, List<TrainingSession>>> timetable
```

Такая структура обеспечивает мгновенный доступ к занятиям без перебора всей коллекции.

### Объектная модель

```
TrainingSession
    ├── Group   (группа участников с возрастной категорией)
    ├── Coach   (тренер)
    ├── DayOfWeek (день недели)
    └── TimeOfDay (время суток: утро / день / вечер)
```

## Запуск

**Требования:** Java 11+

```bash
git clone https://github.com/Ignatio7/java-gym-master.git
cd java-gym-master
javac -d out src/ru/yandex/practicum/gym/*.java
java -cp out ru.yandex.practicum.gym.Main
```
